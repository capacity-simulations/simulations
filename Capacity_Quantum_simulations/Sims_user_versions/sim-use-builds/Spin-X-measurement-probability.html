📖 About the Simulation
Physics:
A spin-½ in a constant magnetic field \(B\hat{z}\) picks up opposite phases on \(|\uparrow\rangle\) and \(|\downarrow\rangle\), producing Larmor precession of the Bloch vector about the z-axis at rate \(\mu B\). Measuring \(\hat S^x\) gives outcomes \(\pm \hbar/2\) with time-dependent probabilities, while the \(\hat S^z\) probabilities stay fixed. The display uses \(\hbar=1\).
Conventions:
The state is restricted to \(\alpha|\uparrow\rangle+\beta|\downarrow\rangle\) with \(\alpha\) real and \(\beta=\sqrt{1-\alpha^2}\), so \(|\alpha|^2+|\beta|^2=1\). Sign convention: \(H=-\omega_{0}\hat S_{z}\), \(\omega_{0}=\mu B\), and \(\hbar=1\).
Visuals:
Top: Bloch sphere showing the Bloch vector \(n=\langle\sigma\rangle\) and its circular precession path (drag to rotate). Bottom: \(P_+\) for an \(\hat S^x\) measurement. The probability axis is fixed to \([0,1]\).
Controls:
\(\alpha\) sets the \(|\uparrow\rangle\) amplitude, \(\beta=\sqrt{1-\alpha^2}\), and \(\mu B\) sets the precession rate. Speed scales the animation clock. Use Reset/Pause to control playback.

Guided Inquiry

1 · Spin in a magnetic field

A spin-½ sits in a uniform magnetic field along z. Its state is α|↑⟩ + β|↓⟩, with β = √(1 − α²), drawn as the arrow on the Bloch sphere. We ask, at every instant, for P+ — the probability that a measurement of Sx returns +ℏ/2.

2 · Prepared along z

Set α = 1: the spin is prepared exactly along +z. What does P+ do as time runs?

3 · Prepared along x

Now α = β = 1/√2, so the arrow starts along +x. Over a long run, what range does P+ cover?

4 · A small tilt

Set α = 0.98, a spin tilted only slightly from +z. Over a long run, what range does P+ cover?

5 · A stronger field

Keep this state and double μB from 1.0 to 2.0. How long does one full cycle of P+ now take?
