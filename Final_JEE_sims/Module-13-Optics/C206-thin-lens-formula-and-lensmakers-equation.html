Topic
Geometrical Optics — thin lens formula & lens-maker's equation (NCERT Class 12).
Concept
The focal length is not a free parameter — it is set by the glass (n) and the surface curvature (R), and once known, one equation places every image.
Serves
Reading a ray diagram; sign convention; the real→virtual transition at u = f; the magnifying glass (u < f).
Inquiry
Place the object at u = 2f — predict where the image lands. Then walk it inward through the focal point.
Misconception target
“A virtual image is not really there.” You see it perfectly well — but no light converges there, so it cannot be caught on a screen.

Guided Inquiry

1. Set the object at u = 2f. Where does the image land?

The focal length here is f = 0.20 m (from R = 0.20 m, n = 1.5). The object sits at u = 2f. Predict.

2. Walk the object inward. What happens to the image?

Slowly drag the Object distance u slider from 0.40 m down toward 0.20 m (= f). Watch the image arrow on the right.

It races outward — the image runs away from the lens far faster than the object approaches it, and grows.

3. Exactly at u = f, what does the picture do?

Set u = 0.20 m — the object sits on the focal point.

4. Now u < f (u = 0.10 m). A friend says “a virtual image isn't really there.”

Set u = 0.10 m. The image is virtual — drawn dashed, on the same side as the object, upright and enlarged (this is the magnifying glass).

5. Free exploration

All three controls are yours. Try: (a) same glass (n = 1.5) with a fatter radius R = 0.24 m — f grows. (b) Denser glass (n = 1.6) with R = 0.24 m — f is 0.20 m again: a fatter radius offset by denser glass. The focal length is not a slider — it is computed from R and n. Two formulae, one mechanism.

Thin lens formula (NCERT)
u > 0 for a real object in front of the lens; v > 0 for a real image on the far side; v < 0 for a virtual image on the same side. m > 0 upright, m < 0 inverted; |m| > 1 enlarged.
Lens-maker's equation (equiconvex: r₁ = +R, r₂ = −R)
Power P = 1/f, in dioptres when f is in metres. f is not a slider — it comes from (n, R) through this equation, then places the image through the formula on the left.
