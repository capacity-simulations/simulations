Concept
The same geometric point has different coordinate labels in different coordinate systems — coordinates describe how we label space, not an intrinsic property of the point.
Serves
Use Cartesian (and polar) coordinates to describe points and trajectories; understand coordinates as labels rather than physical observables; geometry as a mathematical description of space.
Inquiry
Given an (x, y) point, what are its coordinates in the (x′, y′) system? (Set up so it can be read off the grid.)
Reflection
The coordinates changed every time you moved the axes, but the point didn't move — so what exactly are coordinates describing?

Guided Inquiry

1 · Two frames, one marker

Frame S labels the plane with axes x and y. Frame S′ uses axes x′ and y′, rotated counter-clockwise by an angle θ about the same origin O. A single marker sits at one physical location, and each frame assigns it its own pair of numbers.

2 · Which pair is the true one?

Frame S and Frame S′ report different pairs of numbers for the same marker. Which pair is the marker's true position?

3 · What survives a rotation?

Suppose Frame S′ is rotated continuously while the marker stays where it is. Write r = √(x² + y²) and r′ = √(x′² + y′²) for the marker's distance from the origin in each frame. What happens to its S′ numbers?

4 · The frames at 90°

θ is 0°, so the two frames agree and both report (3.0, 2.0). Predict: when θ reaches 90°, what pair will Frame S′ report for the same marker?

5 · A frame that empties one axis

Frame S′ now sits at θ = 90°. Turn it further, until the marker's y′ reads 0 — the marker then lies on the x′ axis itself. What does x′ read there?

6 · Invariants

Across every rotation you set, x′ and y′ changed while r did not. A quantity that comes out the same in every frame is called an invariant; in special relativity the spacetime interval plays exactly the role r plays here.

The Physics

Different coordinate frames · a complete revision sheet · Lecture 1, Geometry

A coordinate isn't a property of a point. It's the answer the axes gave when you asked where the marker is — turn the axes and the answer changes while the marker stays exactly where it was.

01

Why do two frames disagree about one marker?

The sim's two panels at its boot state — one marker, two labels, axes turned by θ = 30° about the shared origin O.
  • Frame S and Frame S′ label the same plane and share the same origin O. Only the axes differ: x′, y′ are turned counter-clockwise by θ.
  • Nothing is done to the marker. The panels differ because each one measures along its own axes.
  • At the boot state S reports (3.0, 2.0) and S′ reports (3.6, 0.2). Both are correct; they answer different questions.
The passive-rotation formulae the sim uses to print the S′ pair.
02

Which way do the numbers move when the axes turn?

Matrix form — R(θ) is the rotation matrix the course writes in Lecture 3.
  • This is a passive rotation: the axes turn by +θ, the marker does not. The component pair therefore turns by −θ.
  • Each component is a perpendicular projection onto one axis — which is why the right angle at O is load-bearing.
  • At θ = 90° the x′ axis lies along y and the y′ axis along −x, so (3.0, 2.0) is relabelled (2.0, −3.0).
  • R(θ) is orthogonal: it re-mixes the two components without stretching either axis. That is the whole reason chapter 03 works.
θ = 60° with the sim's default marker: x′ = 3.2, y′ = −1.6. Both shadows move; the marker does not.
03

What survives the turn?

Whatever θ you set, the r and r′ readouts under the two panels agree.
θ

This is the sim's own rotation slider — drag it here and Frame S′ turns behind the sheet. The marker is where you last dragged it on either panel.

  • x′ and y′ trade value back and forth as θ runs; their squares always add up to the same r².
  • r belongs to the marker, not to the labelling. Distance from O is the one number both frames can agree on.
Turn far enough and one component empties — the surviving one then carries the whole distance.
04

So what is a coordinate, then?

The inverse — the same rule read backwards. It is how a click on the S′ grid becomes an (x, y).
  • The map is invertible, so neither frame knows anything the other doesn't. Neither pair is privileged.
  • Calling S "unrotated" is a convention, not a fact about the plane — nothing in the geometry singles that pair of axes out.
  • In the lecture's own story, S is Bob's coordinate system and S′ is Alice's rotated one: different components, same point.
  • Coordinates are labels we assign, not physical observables. That one sentence is the lecture.
05

Where does this idea go next?

Left: a rotation slides the label round the circle r = const. Right: a boost slides the event along −c²t² + x² = s². Same job, different invariant.
The metric is the machine that builds the invariant: δij for rotations, ημν for boosts.
  • Physics has to be written in quantities every frame agrees on. The course calls those quantities scalars.
  • r here is the prototype: swap the metric δij for ημν and the identical argument produces the spacetime interval.
  • "Invariant" always needs a "under what". δij survives rotations, translations and parity — it does not survive Cartesian → polar.
  • Lecture 4 runs this sim with two markers: Bob reads P = (1, 0) and Q = (1, 1); Alice's rotated frame reads (0, 0) and (√2, 0). Different numbers, same d = √2.
06

The traps they'll set for you

  • "One of the two pairs is the marker's real position." A pair is a position relative to a chosen set of axes; the plane does not nominate a set.
  • "Turning the axes moves the point." That is an active rotation — a different operation. Here the marker holds its place while its labels change.
  • "At θ = 90° you just swap x and y." You swap and flip a sign: x′ = y, y′ = −x, so (3.0, 2.0) becomes (2.0, −3.0).
  • "r′ = r only happens at nice angles." It holds at every θ, to every decimal place — that is what invariant means.
  • "Distance is invariant, so everything is." Components, axis labels and the split of r between them are all frame-dependent.
07

Ninety-second self-test

Drag the marker onto the origin and sweep θ. What do the two panels report?

(0.0, 0.0) in both, at every θ, with r = r′ = 0. With no distance from O there is nothing for the axes to divide up — how much the two frames disagree scales with how far out the marker sits.

Put the marker twice as far from O and double θ. What happens to r′?

r′ doubles, because r doubled. θ has no say: x′ and y′ both change, but x′² + y′² = r² at every angle, so r′ tracks r and nothing else.

Why can no measurement single out Frame S as the "real" one?

Because the transformation is invertible and preserves every distance and angle: x = x′cosθ − y′sinθ, y = x′sinθ + y′cosθ. Anything S can compute, S′ can compute too. "Unrotated" is a label on a convention, not on the plane.
